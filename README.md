# po-translate

Batch translate .po and .ts localization files using AI or free translation services.

Built with Python CLI. Part of the [Danne L10n Suite](https://github.com/yeager/debian-repo).

## Installation

### Debian/Ubuntu
```bash
sudo apt install po-translate
```

### Fedora/RPM
```bash
sudo dnf install po-translate
```
